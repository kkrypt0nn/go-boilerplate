# Security Policy

## Supported Versions

Security fixes will **always** be accepted and taken in consideration if running on the **latest** version of go-boilerplate that isn't marked as pre-release. See the [releases](https://github.com/kkrypt0nn/go-boilerplate/releases) page to know which version is the latest.

| Version  | Supported |
| -------- | --------- |
| v0.\*.\* | :x:       |

## Reporting a Vulnerability

For **usual and non-critical bugs and/or vulnerabilities** please open an [issue](https://github.com/kkrypt0nn/go-boilerplate/issues), or [pull request](https://github.com/kkrypt0nn/go-boilerplate/pulls) if you already have a fix for it. For more important bugs and/or vulnerabilities please contact me per email at [`security@krypton.ninja`](mailto:security@krypton.ninja) or via X (fka Twitter) [`@kkrypt0nn`](https://x.com/kkrypt0nn).
